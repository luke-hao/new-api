# 渠道页手动刷新与检测跟踪

- 渠道列表、分组状态、模型状态和模型总览不再常驻每 5 秒轮询。
- 页面右上角“刷新”一次性更新列表和当前已打开的稳定性状态，不会发起上游检测。
- 打开页面、切换筛选/模型及保存配置仍按需读数据；不因重新聚焦窗口或网络重连自动刷新渠道列表和稳定性状态。
- 仅在当前页面的单模型全测、分组全测或总览全组检测请求被服务端接受后，启动临时刷新。
- 一次读取整个分组状态，更新已缓存的模型状态，并刷新当前列表；若所跟踪任务仍运行，则 5 秒后再次读取。
- 只跟踪手动选择的模型；其他模型的后台自动任务不延长单模型跟踪。分组全测等待所有模型任务完成。
- 结束（包括失败、取消或已快速完成）时同步最终结果并停止；连续三次读取失败也停止并提示刷新失败。
- 切换分组或离开渠道页清理计时器、取消状态请求并忽略旧结果，不取消服务器的探测任务。
- 不改变后端定时检测、优先级、防抖、自动禁用或自动恢复行为。自动恢复仍使用一个渠道测试模型，不是所有模型。
